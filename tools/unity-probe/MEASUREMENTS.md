| High 滚动 -1 / 0.25 / 2；strength=0.1、scroll=1         | **4.82%**    | **8.96%**    |
| High 2 / 4 octaves；multiplier=0.5 / 0.3，scale=2 / 1.7 | **3.93%**    | **9.15%**    |

Low / Medium 均保留 XYZ 输入。空间相关性拟合得到坐标系数 `0.86 / 0.96`；跨频率校准组的首步幅度最小二乘修正后，增益为 `1.87 / 1.26`。留出种子不参与拟合目标；High 继续使用原参数。Octave 对势函数权重归一化，保留各层导数频率；滚动先加到采样坐标，再统一乘空间频率。

运行时新增 **4 个标量常数**，无模型文件、查表资产或新依赖；每系统每 octave 增加 8 字节的预计算权重，不增加逐粒子存储或场采样次数。同机 Node 微基准每 10,000 次求值：单 octave 约 **1.09–1.17 ms**，3 octaves 约 **2.94–2.98 ms**，修改前分别约 **1.14–1.18 / 2.97–3.03 ms**；此结果仅反映 Noise 求值，不代表整帧性能。

Constant Remap ±0.25 与零 Strength 的位置分量差为 **0**。上述范围只覆盖已测空间、种子、时间与参数；仍保留近似诊断，不保证任意配置或同种子轨迹一致。

以下是 **WebGL2 输出与解析公式** 的比较，不是 Unity 最终像素误差。覆盖 Legacy Additive / Alpha Blended、RGB mask、三种雾与软粒子的遮挡 / 部分衰减边界。

| ------------------------ | ------------------------ |

## 多 Mesh 与选择分布

Unity 2022.3.21f1；均匀 / 加权两种模式 × 权重 `1:1:1`、`1:3:6`、`0:1:0`、全零，共 8 组，每组 8,192 粒子。比较每个槽位的频率，误差为 `|Natsume 数量 − Unity 数量| / Unity 数量`；原生为零时要求 Natsume 也为零，不比较同种子逐粒子选择。

| 项目                       | 最大实测差     |
| -------------------------- | -------------- |
| 几何选择频率               | **2.924%**     |
| MeshIndex 行选择频率       | **2.281%**     |
| 原生存活期 Mesh / 行号改变 | **0 / 0 粒子** |

选择频率已低于 10% 统计误差门槛，保留现有随机分布。均匀模式忽略权重；加权模式全零退回均匀。MeshIndex 行沿用均匀选择，独立于加权几何。混合三角形 / 四边形另通过 WebGL2 几何、Pivot、索引重排、粒子减少与序列号替换回归；不将这些解析检查记为 Unity 最终像素误差。尚未测量极小非零权重、更多 Mesh 数量与任意缩放交叉组合。

## 多材质与原生几何限制

Unity 内置 `Hidden/Internal-Colored` 与 Natsume ParticleUnlit 使用相同颜色及混合因子，对照单 submesh Mesh / Billboard 的 1–4 个材质槽、空 Trails 槽、双粒子半透明叠加。材质像素包含 93 个 RGB 通道比较。

| 项目            | 最大实测差                             |
| --------------- | -------------------------------------- |
| 多材质 RGB 像素 | **1/255（0.393% 满量程）**             |
| 多 submesh      | Unity 原生拒绝；Natsume 同样在预检拒绝 |

materials[1] 为 Trails 材质槽，不参与普通粒子绘制；materials[0] 与 materials[2..] 按槽位顺序叠画完整几何，每个材质先完成全部粒子。两个粒子的红 / 蓝半透明对照，Unity RGB=(48,0,191)，Natsume=(48,0,192)。误差按通道满量程 255 归一化，低于本轮 10% 门槛。空主材质会触发 Unity 错误材质或跳过原生 Mesh；Natsume 保留明确阻塞，不自动生成替代材质。

原生多 submesh 探针捕获诊断 `Particle system meshes will only work with exactly one (1) sub mesh`。此项为 Unity 粒子限制，不作为后续待实现能力。未覆盖不同材质 render queue、任意宿主混合与全部多 Mesh 交叉组合；透明顺序仅测同队列。

## 尚未量化

- 任意 Shape / 模拟空间 / Renderer 参数交叉组合，透视视图、跨系统 sortingFudge 最终像素、min/max size 的 Unity 像素差。
