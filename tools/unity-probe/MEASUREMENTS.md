# Unity 行为对照

基准版本：Unity **2022.3.21f1**。固定输入案例使用 `1/60 s` 步长；随机分布每组采样 16,384 粒子。以下结论仅覆盖已测配置。

“实测差异”指已记录的比较结果；“回归容差”指测试允许的差值，不代表实测最大误差。位置、速度和尺寸均使用测试场景单位，颜色归一化至 `[0,1]`。

## 曲线

| 项目                 | Unity 行为与 Natsume 对齐结果                              | 误差说明                       |
| -------------------- | ---------------------------------------------------------- | ------------------------------ |
| Unity 内部循环码 `2` | 两端钳制，右端点保留末值；对应公开 `Once` / `ClampForever` | 已核对行为，未汇总数值最大误差 |

测量曲线为 `(0,2)` 至 `(1,6)`，两端斜率均为 4；覆盖区间内、负时间、越界与整周期边界。

## 运动与外观

边界探针共 37 个案例。运动与外观数值摘录比较第 `0、1、4、30、59` 帧。

| 项目                      | Unity 行为与 Natsume 对齐结果                                                         | 回归容差                              |
| ------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------- |
| Linear / Radial / Orbital | Linear、Radial 叠加基础速度；Orbital 按 ZXY 顺序旋转位置；Radial 使用旋转后的位置方向 | 位置、velocity 各分量绝对差 < 5×10⁻⁵  |
| Speed Multiplier          | 同时影响平移速度与轨道旋转角                                                          | 同上                                  |
| 标量 Limit Velocity       | 在 Speed Multiplier 前限制合成速度，并将速度差写回基础 velocity                       | 同上                                  |
| 生命周期尺寸              | 按曲线缩放初始尺寸                                                                    | 各分量绝对差 < 5×10⁻⁵                 |
| Blend / Fixed 渐变        | 渐变结果与初始颜色相乘                                                                | RGBA 各通道绝对差 ≤ 2/255，约 0.00784 |

Limit 测量例：`limit=0.12`、`dampen=0.26`、初速度 `(10,0,0)`。dt=1/60 时首步速度为 8.6190977、位置 X 为 0.14365163；dt=1/120 时首步速度为 9.2835732。

## 渲染几何

对照 Unity `BakeMesh` 顶点与 UV，不包含材质或最终像素颜色比较。

| 项目                | Unity 行为与 Natsume 对齐结果                                                       | 误差说明                                                                     |
| ------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| World Billboard     | 粒子 Euler 角取反，按 ZXY 旋转                                                      | 顶点距离回归容差 < 10⁻⁵                                                      |
| Mesh World / View   | 保留粒子 Euler 角符号，按 ZXY 旋转；覆盖节点绕 Z 旋转 90°                           | 顶点距离回归容差 < 10⁻⁵                                                      |
| Stretched Billboard | 正长度向速度反方向展开；负长度反向并翻转横向边；UV.x=0 端锚定粒子位置；使用合成速度 | 组合速度案例长度实测差异约 0.1%；该案例顶点距离回归容差 < 0.015，其余 < 10⁻⁵ |

Stretch 已测范围：`cameraVelocityScale=0`、`velocityScale=0`、`rotateWithStretchDirection=true`，非 Freeform，沿 +Z 观察，速度位于 XY 平面。

## 粒子排序

Unity 2022.3.21f1 正交相机下，3 个手动粒子的 BakeMesh 索引顺序对照：

| 模式             | Unity / Natsume 顺序 | 索引差异 |
| ---------------- | -------------------- | -------- |
| None             | 0, 1, 2              | 0        |
| Distance / Depth | 0, 2, 1              | 0        |
| OldestInFront    | 0, 2, 1              | 0        |
| YoungestInFront  | 1, 2, 0              | 0        |

输入 Z 为 `[3,1,2]`，年龄为 `[0.2,0.8,0.5]` 秒，寿命均为 1 秒。未测透视相机、Unity 同深度粒子的稳定顺序及跨系统 sortingFudge 的最终像素。

## 随机分布与形状

随机分布与形状各 14 组案例。随机参数分布归一化至 `[0,1]` 后比较；位置扰动统计保留场景单位。随机结果不要求相同种子逐粒子一致。

| 项目                               | Unity 行为与 Natsume 对齐结果                                                    | 回归容差或实测差异                                                                |
| ---------------------------------- | -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Circle 半径与弧度                  | 内外环之间按半径平方均匀采样；覆盖三个整圆种子、四种半径厚度及 90° / 270° 弧     | 均值差 < 0.018、方差差 < 0.007、16 桶占比差 < 0.018                               |
| 寿命、速度、初始尺寸 / 旋转 / 颜色 | 已测随机参数分布一致；初始尺寸和旋转各轴独立                                     | 同上                                                                              |
| 生命周期尺寸随机值                 | 三轴共用同一插值因子                                                             | 三轴归一化因子差 < 10⁻⁶                                                           |
| 位置扰动                           | 固定长度球面采样，随后应用 Shape 缩放和旋转；不改变初速度方向；Z 缩放为 0 时压平 | 各轴均值、二阶矩差 < 0.06；半径平方均值差 < 0.08；方差差未旋转 < 10⁻⁶、旋转 < 0.2 |
| Burst Spread                       | 部分弧包含首尾；整圆排除重复终点；覆盖 1 / 2 / 3 / 8 粒子及 90° / 360° 弧        | 位置各分量回归容差 < 5×10⁻⁶                                                       |

已知差异：Unity 中速度与生命周期尺寸随机值存在约 0.12–0.13 的弱相关，Natsume 未拟合；零半径 Shape 在 Unity 中仍有约 10⁻⁴ 半径，Natsume 使用精确 0。

## 基础 Shape 扩展

新增 31 组原生采样，每组 16,384 粒子；其中 30 组参与 Natsume 分布比较，Align to Direction 仅保留原生数据，尚未实现。位置和速度均在 Shape TRS 之前比较，不要求随机序列逐粒子一致。

| 项目                      | Unity 实测语义                                                               | 差异说明          |
| ------------------------- | ---------------------------------------------------------------------------- | ----------------- |
| Sphere / Hemisphere       | 球体体积按半径立方采样；Hemisphere 位于 +Z 半球                              | 下列合计统计范围  |
| Box Volume / Shell / Edge | 体积、面、边分别采样；Shell / Edge 厚度向负角收缩                            | 下列合计统计范围  |
| Cone Base / Volume        | 底面按平方半径采样；Volume 沿归一化发射方向均匀取长度                        | 下列合计统计范围  |
| Edge                      | 沿 X 轴采样，默认初速度 +Y；三组厚度下初速度均值 / 最小 / 最大均为 `(0,1,0)` | 方向与 Unity 一致 |
| 随机 / 球面方向           | 对局部初速度方向插值后归一化                                                 | 下列合计统计范围  |

30 组、Natsume 种子 12345 的最大实测统计差：各轴均值 **0.01741**、二阶矩 **0.02191**，半径均值 **0.00582**、半径二阶矩 **0.00916**。包含位置与单位速度，均为绝对差，不能解释为逐粒子误差或百分比。对应回归容差依次为 0.025、0.035、0.025、0.045。

## 旋转与预热

| 项目                   | 已测范围                                                                                   | 差异说明                                             |
| ---------------------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| Rotation over Lifetime | Z / XYZ 常量角速度，以及生命周期线性曲线；取步进前的粒子年龄采样，dt=1/60                  | 各轴角度绝对差回归容差 < 10⁻⁵ rad                    |
| 循环预热               | 5 组直接 Play，duration 为 1 / 3 秒，常量寿命为 1 / 2 / 4 秒；预模拟完整周期至覆盖最大寿命 | 已测计数差 ≤ 2 粒；剩余寿命中位数差回归容差 < 0.12 s |

预热的发射与死亡边界仍有差异，不保证逐粒子年龄或随机序列相同。曲线寿命预热尚未支持；`Simulate(0, restart=true)` 后 Play 的启动状态与直接 Play 不同，不计入上述比较。

模拟倍速对照覆盖 0 / 0.5 / 2：零倍速冻结推进且不预热；非零倍速缩放运行时间，预热仍覆盖相同模拟时长。旋转角度回归容差为 2×10⁻⁵ rad，预热沿用计数差 ≤ 2 和中位寿命差 < 0.12 s。

## Noise 近似

| 项目            | 已对齐语义或测量结果                                                                            | 误差说明                             |
| --------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------ |
| 位置扰动        | 在基础速度积分前采样；可改变位置而不改变 GetParticles.velocity；同一局部坐标下不受物体 TRS 影响 | 行为核对                             |
| Damping         | 已测非零频率组合中，幅度除以 frequency                                                          | 行为核对                             |

近似范围：High、1 octave、scroll=0、remap 关闭、仅位置扰动。Natsume 使用纯 TypeScript Curl Noise；不复现 Unity 的原生噪声函数和同种子轨迹。
