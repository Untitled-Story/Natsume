# Unity 行为对照

复测时间：**2026-10-18 05:49:24 UTC**。Unity **2022.3.21f1**，固定步长 `1/60 s`；浏览器为 Chromium / WebGL2。14 种原生探针、212 项单元测试与 20 项浏览器测试已运行。

下表为本次采样的**最大实测绝对差**，数值四舍五入，不再以测试容差代替误差。`0` 仅表示已测输入相同；位置 / 速度使用场景单位，角度为 rad。随机分布比较统计量，不要求同种子逐粒子一致。已知近似的测量测试只检查数据有效，测试通过不代表数值一致。

完整数值、比较次数、误差 RMS、最大差对应案例和输入 SHA-256 见 [measurements.json](measurements.json)。本次记录 6,519 个标量比较、102 项指标；不同单位不合并为整体百分比。

| Mesh                  | World / View / Local、粒子旋转与旋转节点                        | 顶点距离 **1.527×10⁻⁶**                                     |

普通 Stretch 使用 `粒子速度 - viewVelocity × Camera Velocity Scale`；长度为 `sizeY × Length Scale + 相对速度长度 × Velocity Scale`，保留负系数。Unity 的快速归一化与 Natsume 精确归一化存在小幅差异；斜向 XYZ 横边另有粒子到相机射线与固定 +Z 视图的差异。

Pivot 的非零偏移与旋转组合尚未对齐，本次只记录，未修改运行算法。Flip 的随机概率只在功能测试中检查；上述原生数值覆盖确定性翻转。

## Noise

原有 High / 单 octave 校准保留；新增 **18 组**空间总体采样：种子 `2`、`4294967295`，每组 512 个固定 LCG 空间点，坐标位于 `[-16,16)`，粒子种子 `1000+i`。不匹配 Unity 的逐粒子随机轨迹。

下表为两个种子之间的**相对 RMS 统计差范围**：`|RMS(Natsume) - RMS(Unity)| / RMS(Unity)`。位置行比较总体位移 RMS，首步可反映噪声幅度，1 秒结果还包含噪声积分与空间移动；不能解释为逐粒子位置百分比。

| 配置                                     | 首步统计差       | 1 秒统计差       |
| ---------------------------------------- | ---------------- | ---------------- |
| High、单 octave、strength=0.03           | **4.49–4.64%**   | **4.51–4.62%**   |
| High、单 octave、strength=1              | **4.49–4.64%**   | **3.22–4.59%**   |
| Low                                      | **52.62–54.19%** | **47.96–48.05%** |
| Medium                                   | **21.40–27.40%** | **19.27–25.46%** |
| High、Scroll Speed=1                     | **4.37–4.38%**   | **20.14–21.47%** |
| High、3 octaves、multiplier=0.5、scale=2 | **13.93–15.18%** | **20.23–23.71%** |
| Frequency=0，High                        | **1.93–1.94%**   | **1.93–1.93%**   |
| 仅旋转：角度向量 RMS                     | **4.49–4.64%**   | **4.49–4.64%**   |
| 仅尺寸：XY 渲染尺寸变化 RMS              | **6.19–8.74%**   | **6.19–8.74%**   |

除表内指定项外，frequency=0.28、strength=1、damping 开启、High、单 octave、无滚动。尺寸比较 BakeMesh 的 XY 绝对宽高变化；Unity GetCurrentSize 不包含这项影响。旋转为对应噪声速率的 `0.5 × dt`（角度制），尺寸因子为 `1 + noise × 0.5 × amount`，尺寸不累积。

Constant Remap ±0.25 与零 Strength 的位置分量差为 **0**。Low / Medium 降维、多 octave 与 Scroll 仍是近似；本批数值说明它们不能沿用 High 的误差结论。先前约 5.1% 来自另一批留出采样，只描述原校准配置的幅度；本次未重新拟合算法。

## 尚未量化

- 任意 Shape / 模拟空间 / Renderer 参数交叉组合，透视视图、跨系统 sortingFudge 最终像素、min/max size 的 Unity 像素差。
- 非恒定 Custom Color、随机 Custom 分量的原生分布、软粒子的真实游戏背景深度，以及未支持模块。
- Script Bridge、Animator / active 与暂停 / 重启 / 销毁运行了功能回归；它们没有可合并为数值误差的通用 Unity 游戏脚本基准。95 个游戏包的整包视觉误差未在本次测量。
